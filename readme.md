
# English Buddy Pro v2.1

An AI-powered English Learning Platform designed primarily for Hindi speakers.

## Vision

Learn English with the help of Artificial Intelligence.

The platform combines:

- AI Tutor
- Grammar Coach
- Translation
- Vocabulary Builder
- Speaking Practice
- Pronunciation Coach
- Interview Preparation
- Writing Assistant
